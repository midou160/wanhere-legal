# صفحات WanHere العامة

الصفحات منشورة بالفعل على GitHub Pages؛ لا تنشئ مستودعًا جديدًا ولا تعِد رفعها:

- سياسة الخصوصية: https://midou160.github.io/wanhere-legal/
- شروط الاستخدام: https://midou160.github.io/wanhere-legal/terms.html
- حذف الحساب: https://midou160.github.io/wanhere-legal/delete-account.html

تحققت في 9 أكتوبر 2026 أن الروابط الثلاثة تفتح بنجاح (`HTTP 200`). كما تحققت أن صفحة حذف الحساب تستطيع جلب إعداداتها العامة من Supabase، وأن طلبات التحقق المبدئية من صفحة GitHub Pages مقبولة. لم أرسل طلب حذف لحساب حقيقي.

وظيفة `account-deletion-web` منشورة ونقطة إعداداتها تعمل؛ لا حاجة إلى تشغيل `npx supabase functions deploy account-deletion-web` ما لم يتغير كود الوظيفة مستقبلًا.

عند فتح حساب Google Play Console لاحقًا، استخدم رابط سياسة الخصوصية ورابط حذف الحساب في بيانات المتجر المطلوبة. هذا مؤجل حاليًا مع تأجيل إنشاء حساب المتجر.

دومين `tdriss.com` المستخدم في Resend لإرسال البريد لا يعني تلقائيًا وجود موقع أو صفحة تحويل للمصادقة عليه. جذر الدومين أعاد `404` عند الفحص، لذلك لا تستخدمه كرابط لموقع أو callback قبل نشر صفحة مناسبة عليه. إعداد إرسال البريد في Resend مستقل عن نشر صفحات GitHub Pages.

لا تضع هنا ملفات `.env` أو مفاتيح سرية؛ مفاتيح الإرسال العامة الظاهرة على موقع الحذف ليست مفاتيح `service_role`.
